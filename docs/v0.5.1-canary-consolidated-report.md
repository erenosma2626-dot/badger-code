## 3. Öne Çıkan En Kritik İki Bulgu

### (a) `agent.py:831`'in `write_file`'ı Stuck-Loop Denetiminin Dışında Bırakması (Scaffold Kör Noktası)
- **Bulgu:** `starter/agent/agent.py` Satır 831'de yer alan denetim:
  ```python
  if name in ("terminal_exec", "read_file"):
  ```
  `write_file` aracını tamamen dışarıda bırakmaktadır.
- **Somut Etkisi:** `regex-log` Run 2'de model Turn 5'ten (Msg 10) Turn 100'e (Msg 200) kadar **tam 95 tur boyunca** `/app/regex.txt` dosyasına birebir aynı parametrelerle `write_file` yazmıştır. Ancak `write_file` bu bloğa girmediği için ne `fingerprint` üretilmiş, ne `exact_repeat_stuck` ne de `cyclic_target_history` güncellenmiştir.
- **Durum:** Bu durum gerçek bir scaffold bug'ıdır / kör noktadır. Henüz kodlanmadı, Lead onayı beklemektedir.

### (b) `LLM_MAX_TOKENS=4096`'nın `regex-log` Görevinde `finish_reason=length` Tetiklemesi
- **Bulgu:** Model, satırdaki son tarihi eşleştirmek için yüzlerce negatif lookahead (`(?!\S*\S*\S*...)`) içeren patolojik regex'ler üretmeye kalktığında 4096 token sınırına çarpmaktadır.
- **Somut Etkisi:**
  - `regex-log` Run 3'te 11 turun **11'inde de** istisnasız `finish_reason=length` gerçekleşmiş ve her tur tam 4096 token üretilmiştir (Toplam 45.056 token). Tool-call JSON'ı yarıda kesildiği için harness geçerli bir araç çağrısı algılayamamış, her tur ~80s yanıt süresi alarak 11. turda 900s duvar saati aşılmıştır (`AgentTimeoutError`).
  - Run 1'de de 29 turun 14'ü `finish_reason=length` ile kesilmiştir.
- **Durum:** Sorunun kökü modelin devasa regex üretme davranışıdır (polyglot-c-py'deki gibi); ancak 4096 tavanı bu kesilmeyi garantilemektedir. Henüz aksiyon alınmadı, Lead onayı beklemektedir.

## 4. Sıradaki Adaylar Listesi (Kodlanmadı, Sadece Öneri/Liste)

1. **`write_file` blind-spot düzeltmesi (`agent.py:831`):**  
   `if name in ("terminal_exec", "read_file", "write_file"):` yapılarak `write_file` çağrılarının da parmak izi, ardışık tekrar ve döngüsel hedef takibine dahil edilmesi.
2. **Parçalı-yazma / regex prompt kuralı:**  
   Negatif lookahead zincirleme yasağının güçlendirilmesi; karmaşık mantığın devasa regex yerine Python kodu içinde satır satır işlenmesi talimatı.
3. **`build-cython-ext` Python3 path uyuşmazlığı:**  
   Ortamdaki `/usr/local/bin/python3` ile Debian sistem python'u (`/usr/bin/python3`) ayrımına karşı rehberlik veya modül kurulumunda `python3 -m pip install` kullanımının teşvik edilmesi.
